# Requirements

* C/C++: `clangd`, `cpplint`, `clang-format`
* Python: `pyright`, `ruff`
* Shell: `bashls`, `shellcheck`, `shfmt`
* Text: `textlsp`, `markdownlint`, `bibtex-tidy`, `tex-fmt`
* Others: `vscode-html-languageserver`, `vscode-json-language-server`, `asm-lsp`, `harper`

## Arch linux

* `pacman -S vscode-html-languageserver vscode-json-languageserver pyright ruff-lsp bash-language-server shellcheck shfmt markdownlint harper python-setuptools`
* `cargo install asm-lsp tex-fmt`
* `pix install textlsp`
* `sudo npm install -g bibtex-tidy`
